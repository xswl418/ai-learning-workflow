# 示例：进入数据分析领域

这是虚构的流程示例。人物情况、任务、数据、回答与接续状态均为构造，不是真实学习记录，也不是招聘要求调研。

## S1：目标与起点

学习者希望从现有工作转向数据分析，当前具体目标是能够从小型业务表中计算指标、核对口径，并解释结果。

设定条件：每周可安排约六小时；能操作表格筛选，自述知道“转化率”，尚无独立汇总分析证据。学习者不知道怎样安排先后。

先用短题判断起点：表中两行分别有多少访问、多少成交，整体转化率需要哪些数据？构造回答是“算两行转化率再取平均”。据此只确认存在聚合口径疑问，不推断全部统计基础薄弱。

## S2：资料与能力要求

本例使用一份虚构练习说明：每行代表一个渠道某日的数据；访问数与成交数口径一致，成交数不超过访问数；本任务整体转化率定义为总成交数除以总访问数。

| 来源编号 | 内容 | 支持范围 | 限制 |
| --- | --- | --- | --- |
| SRC-A | 本例练习说明与下表 | 本次指标定义、样例计算 | 不能推广为所有公司的统一口径 |
| SRC-B | 学习者未来提供的目标岗位材料 | 待核实 | 本例没有检索或宣称当前岗位要求 |

先围绕已确认的练习目标学习，职业路线待真实资料补充后再细化。

## S3：首版总清单

计划版本：DEMO-A-v1。AI 推荐 P1 → P2 → P3，学习者接受。投入估计仅用于本例安排，后续按表现调整。

| 阶段 | 小能力与用途 | 前置 | 难度与投入估计 | 推荐理由及暂缓影响 |
| --- | --- | --- | --- | --- |
| P1 | 看懂行粒度、字段和指标分母 | 基本四则运算 | 低至中，约一至两次学习 | 支持正确汇总；跳过易选错分母 |
| P2 | 按条件汇总并核对整体比例 | P1 的指标口径 | 中，约两至三次学习 | 把口径用于任务；暂缓则无法独立汇总 |
| P3 | 简短解释结果及限制 | P1、P2 的计算结果 | 中，约一至两次学习 | 将数字用于说明；不能靠漂亮图表替代计算核对 |

### P1 阶段清单

| 项目 | 具体内容 |
| --- | --- |
| 任务目标 | 区分行内比例和整体比例，能选择本题所需分母 |
| 实现流程逻辑 | 读每行含义 → 确认分子分母 → 汇总数量 → 相除 → 检查范围和空分母 |
| 预期掌握结果 | 能按给定口径算整体比例，识别直接平均的风险，处理分母为零 |
| 测试检查 | C1 公式选择；C2 改变访问规模的变式；C3 零分母判断 |
| 边界检查 | 本例不讨论去重用户、跨日重复、因果推断；结果只对应给定口径 |

## S4：讲解与首次示范

当前活动是听讲。先说明整体比率要把总量放在一起，行内比例对应各自的分母。不同规模的行直接平均，相当于不区分规模地给予相同权重。

首个小例子可用访问数相同的两行示范计算，再说明这种情况下直接平均碰巧相等，不能据此推广到规模不同的情况。

接着给本题数据：

| 渠道 | 访问数 | 成交数 |
| --- | ---: | ---: |
| 甲 | 100 | 20 |
| 乙 | 900 | 90 |

## S5—S6：尝试、提示与检查

当前活动切为尝试，C1 只要求选择表达式，不要求长篇解释：

| 选项 | 整体转化率的表达式 |
| --- | --- |
| A | `(20/100 + 90/900) / 2` |
| B | `(20 + 90) / (100 + 900)` |
| C | `(100 + 900) / (20 + 90)` |

假设学习者选A。AI 先指出两行的访问量不同，提示关注整体分母；若仍卡住，再局部示范“先把访问数加起来”。构造记录为：局部提示后选B，计算得11%。

然后提供C2：将乙行改成访问100、成交10。要求在相同选项结构下选择并计算。此时正确的整体比率为15%，且简单平均也等于15%，所以这一数值任务不能独自区分两种方法。

因此再用C2b：甲为访问200、成交20，乙为访问800、成交160。若学习者选出总量比并得到18%，才增加“在该规模变化中选用正确口径”的证据；仍不能宣称掌握全部统计汇总。

C3：总访问数为0时，应怎样做？

- A：报告本口径比率不可计算，并说明分母为0。
- B：一律报告0%。
- C：沿用上一期数值。

记录实际选择；若选A，只确认本例零分母规则的局部理解。

### 阶段记录示意

记录编号 DEMO-A-R1，以下结果均为构造：

| 编号 | 实际表现 | 帮助条件 | 可支持的结论 |
| --- | --- | --- | --- |
| C1 | 先选A，局部提示后改选B并算11% | 得到分母提示 | 提示后完成本题 |
| C2 | 算15% | 无新增提示 | 结果正确，但不能单独辨别两种方法 |
| C2b | 选总量比并算18% | 可查本单元笔记，无新增提示 | 完成该变式，仍需后续结合任务观察 |
| C3 | 选A | 无新增提示 | 识别本题零分母处理 |

## S7：回顾与调整

串联“行粒度 → 指标口径 → 汇总 → 检查”。回顾的错误是将不同分母下的比例直接平均，不再重做所有同类表。

假设学习者中断后回来，AI 建议先做一题口径复习。学习者表示时间紧，拒绝复习，希望先看结果解释。AI 说明P3依赖计算核对，随后接受先进入P3的选择；保留P2尚未完成的记录。

如果以后目标岗位材料要求另一套指标定义，应核实定义、说明影响并提出改版；不能把本例口径直接当成行业标准。

## S8：当前接续示意

以下可独立携带给新会话：

```text
计划：DEMO-A-v2；整体路线P1→P2→P3，学习者已选择先进入P3。
当前：P1本轮收束；P2暂缓；P3尚未讲解。
依据：DEMO-A-R1。C1局部提示后完成；C2无法区分方法；
      C2b和C3有构造的局部证据，不等于全部指标分析掌握。
决定：中断后建议复习，学习者拒绝；不再重复要求复习。
下一动作：AI用已有11%结果示范“结论—口径—限制”的说明结构，
          再请学习者为C2b结果选择一个说明。
完成标准：说明与数值、口径一致，不从比例差异推断因果。
尚未完成：P2的独立表格汇总，不得恢复成已通过。
```

此处跳过P2是学习顺序的选择，不是能力认证。新会话应开始P3的具体动作，不恢复旧版“先做P2”的待办。
